# NPS Watch — 국민연금 포트폴리오 모니터

국민연금의 공개 자산배분과 5% 대량보유 공시를 확인하고,
사용자가 자신의 자산 구성을 점검할 수 있도록 돕는 **참고용 도구**.

> ⚠️ 본 서비스는 투자 자문·권유가 아니며, 모든 계산은 참고용 산술 비교입니다.

---

## 🧭 정보 구조 (3가지 사용자 질문 기준)

| 질문 | 화면(탭) | 데이터 상태 |
|---|---|---|
| Q1. 국민연금은 어디에 투자하고 있나? | 📊 국민연금 포트폴리오 | **샘플** (실데이터 연동 예정) |
| Q2. 최근 무엇을 늘리고 줄였나? | 🏆 5% 공시 · 📋 국내주식 | **실 API** (OpenDART) |
| Q3. 내 자산과 비교하면? | 📐 내 자산과 비교 | 클라이언트 계산 (참고용) |

## 📊 데이터 소스 및 상태

| 데이터 | 상태 | 출처 | 갱신 |
|---|---|---|---|
| 5% 대량보유 공시 | ✅ 실 API | OpenDART `list.json`(D001) + `majorstock.json` | 조회 시점, CDN 10분 캐시 |
| 보고일 종가 (평가액 계산용) | ✅ 실 API | Yahoo Finance chart API (비공식) | 보고일 ±7일 근접 거래일 |
| 자산군 배분 / 연도별 추이 / KPI | 🟡 **샘플 하드코딩** | (연동 예정: fund.nps.or.kr) | 수동 |
| 섹터 분류 | 🟡 하드코딩 dict (`SECTOR_MAP`, ~120종목) | 자체 분류 | 코드 수정 시 |

UI에는 모든 섹션에 `샘플` / `공시 기준` / `이전 데이터` 상태 뱃지가 표시됩니다.

## 🧮 주요 계산식

- **변동 평가액** = `stkqy_irds(변동주식수) × 보고일 종가` — *추정치, 실제 매매단가와 다를 수 있음*
- **보유 평가액** = `stkqy(보유주식수) × 보고일 종가`
- **시가총액(근사)** = `보유 평가액 × 100 ÷ 지분율`
- **모드 C 배분 가중치** = 시가총액(근사) 비중.
  ⚠️ **5% 공시 지분율(stkrt)은 배분 가중치로 사용하지 않음** — 이는 "NPS가 그 회사의 몇 %를 보유"이며 NPS 포트폴리오 내 종목 비중이 아니기 때문 (v10에서 지분율 가중 옵션 제거됨)
- **배분 유사도** = `1 − Σ|내 비중 − 참고 비중| ÷ 2` (L1 norm)

## 🚨 오류 처리 흐름

API 실패 시: ① 마지막 성공 캐시("N시간 전 데이터" 표시) → ② 코드 내 샘플("(샘플)" 접두어) 순 폴백.
상태 뱃지가 `공시 기준(초록)` → `이전 데이터(빨강)` / `샘플(빨강)`으로 전환되고 "새로고침" 재시도 링크 제공.

검증 포인트:

2. 5% 공시: 상태 뱃지 / 필터 / 검색 / 정렬 / ★관심 / 용어 도움말
3. API 차단 시: 무한 로딩 없이 "갱신 실패 + 이전 데이터/샘플" 표시 + 재시도
4. 모바일 390·360px: 가로 스크롤 없음, 탭·버튼 터치 44px
5. 시뮬레이터: 금액 미입력 시 안내, 계산 전·후 "참고용" 고지 노출
